# ytmp34

YouTube to MP3 / MP4. No ads, no redirects. **https://rquw.github.io/ytmp34**

Hosted on Oracle Cloud (Always Free)
Server might go down every now and then. Send an E-Mail to [rquw@icloud.com](mailto:rquw@icloud.com) if you catch it being down!
There is also a Shortcut feature. Drag the MP3 and MP4 Shortcuts into your Bookmarks, and whenever you click on one of them, it instantly starts converting and downloading!
